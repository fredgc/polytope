# Commandes

La barre supérieure contient plusieurs commandes :

1. **Type de polytope** : Choisissez le polytope régulieràafficher.

2. **Dimension** : Choisissez la dimension (de 2à5).

3. **Basculer la coupe** : Activez ou désactivez la coupe par un hyperplan.

4. **Menu Transformation** : Sélectionnez les modes de rotation (R3, R4, R5),
   Zolly ou Translation.

## Gestes et vitesse

* **Glisser** : Fait pivoter ou déplace le polytope selon le mode actif.

* **Faire défiler / Pincer** : Zoome ou redimensionne le polytope.

* **Balayer rapidement** : Donne de l'élan pour poursuivre la rotation ou la
  coupe de manière fluide.

* **Toucher** : Arrête le mouvement.

## Alignements rapides

Alignez rapidement le polytope pour qu'un sommet, une arête, une face ou une
3-cellule soit orientédirectement vers l'écran.
