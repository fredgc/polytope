# Commandes

La barre supérieure contient plusieurs commandes :

1.  **Paramètres** (icône d'engrenage) : Configure les couleurs, l'épaisseur
    des arêtes/sommets, le découpage des lignes, le thème et les boutons à
    l'écran.

2.  **Type de polytope** : Sélectionne le polytope régulier à afficher
    (Simplexe, Cube, Orthoplexe, Dodécaèdre, Icosaèdre, 24-cellules,
    120-cellules ou 600-cellules).

3.  **Dimension** : Choisit la dimension (de 2 à 5).

4.  **Coupe (Slice)** : Active ou désactive l'intersection avec l'hyperplan.

5.  **Menu Mouvement / Transformation** : Sélectionne le mode (`Rotate R3`,
    `Rotate R4`, `Rotate R5`, `Zolly`, `Translate` ou `Scale`) ou l'alignement
    (sommet, arête, face ou 3-cellule devant).

6.  **Aide** (`?`) et **Langue** (icône globe) : Ouvre la documentation ou
    change la langue.

## Web et Ordinateur (Souris et Clavier)

-   **Glisser** : Fait pivoter, ajuste la perspective (`Zolly`), déplace ou
    redimensionne selon le mode actif.

-   **Molette** : Effectue un zoom avant ou arrière.

-   **Lancer (Fling)** : Donne une vitesse en `Rotate R3` ou sur le curseur de
    coupe pour un mouvement continu.

-   **Clic / Appui** : Arrête la rotation sur le canevas ou positionne et
    arrête le curseur de coupe.

-   **Flèches directionnelles** : Appliquent l'outil de mouvement actif.

-   **`]` / `[`** (ou **Page préc. / Page suiv.**, **Pavé num. `+` / `-`**) :
    Zoom avant ou arrière.

-   **Touches de modification** : Maintenez **Maj** (`Rotate R4`),
    **Maj+Ctrl** (`Rotate R5`), **Ctrl** (`Zolly`), **Alt** (`Translate`) ou
    **Ctrl+Alt** (`Scale`).

-   **`0`, `1`, `2`, `3`** : Aligne un sommet, une arête, une face ou une
    3-cellule devant.

-   **Espace** : Met en pause la rotation et la coupe lorsque le canevas a le
    focus.

-   **`+` / `-`** (ou `=`) : Accélère ou ralentit l'animation de coupe.

## Mobile (Tactile)

-   **Glisser, lancer et appuyer** : Faire pivoter, déplacer, lancer la
    rotation ou appuyer pour l'arrêter.

-   **Pincer et tourner** : Pincer à deux doigts change l'échelle ; pivoter à
    deux doigts tourne dans le plan de l'écran.

-   **Boutons raccourcis à l'écran (`S`, `C`, `A`)** : Affichés par défaut sur
    téléphones et tablettes (réglable dans Paramètres) comme équivalents
    tactiles de Maj, Ctrl et Alt.

-   **Boutons panoramique/zoom à l'écran** : Optionnels dans Paramètres. Un
    double appui sur une flèche en `Rotate R3` accélère la rotation ; le
    bouton central Arrêt la stoppe.

## Android TV (Télécommande D-Pad)

*Cette section concerne uniquement Android TV.*

-   **Navigation** : Utilisez les flèches du D-Pad et **Sélectionner** pour
    naviguer dans la barre supérieure, les boutons de rotation/zoom et le
    curseur de coupe. **Bas** depuis la barre supérieure ou **Haut** depuis le
    curseur de coupe place le focus sur le bouton central de rotation.

-   **Mode rotation active** :

    -   **Appui long sur Sélectionner** sur le bouton central **Arrêt** active
        le **Mode rotation active** (l'icône devient un globe mis en
        évidence).

    -   **Appui court sur une flèche** : Augmente la vitesse de rotation dans
        cette direction.

    -   **Appui long sur une flèche** : Fait pivoter régulièrement tant que la
        touche est maintenue.

    -   **Appui court sur Sélectionner** : Arrête la rotation tout en restant
        en Mode rotation active.

    -   **Appui long sur Sélectionner** ou touche **Retour** : Quitte le Mode
        rotation active.

-   **Curseur de coupe** : Placez le focus sur le curseur et appuyez sur
    **Sélectionner** pour démarrer ou arrêter l'animation, ou utilisez
    **Gauche / Droite** pour avancer manuellement.

-   **Paramètres** : Utilisez **Haut / Bas** pour parcourir les réglages ligne
    par ligne. Sur un curseur, appuyez sur **Sélectionner** pour éditer,
    **Gauche / Droite** pour ajuster, puis **Sélectionner** ou **Retour** pour
    valider.
