# 操作控制

顶部栏包含多个控件：

1.  **设置**（齿轮图标）：配置颜色、边/顶点粗细、线条裁剪、主题明暗和屏幕
    按钮。

2.  **多胞体类型**：选择要显示的正多胞体（单纯形、超立方体、正轴体、
    正十二面体、正二十面体、正24胞体、正120胞体或正600胞体）。

3.  **维度**：选择维度（2 至 5）。

4.  **切片开关**：开启或关闭超平面截面切片。

5.  **移动 / 变换菜单**：选择拖动和按钮模式（`Rotate R3`、`Rotate R4`、
    `Rotate R5`、`Zolly`、`Translate` 或 `Scale`），或快速对齐方向（顶点、
    边、面或 3-胞体朝前）。

6.  **帮助**（`?`）和**语言**（地球图标）：打开帮助文档或切换界面和文档
    语言。

## Web 与桌面端（鼠标与键盘）

-   **拖动**：根据当前移动模式旋转、透视缩放（`Zolly`）、平移或缩放。

-   **鼠标滚轮**：放大或缩小。

-   **轻扫（Fling）**：在 `Rotate R3` 或切片滑块上赋予速度，使其持续平滑
    运动。

-   **点击 / 轻触**：停止画布上的旋转，或跳转并停止切片滑块。

-   **方向键**：应用当前移动工具。

-   **`]` / `[`**（或 **Page Up / Page Down**、小键盘 **`+` / `-`**）：
    放大或缩小。

-   **修饰键**：按住 **Shift**（`Rotate R4`）、**Shift+Ctrl**
    （`Rotate R5`）、**Ctrl**（`Zolly`）、**Alt**（`Translate`）或
    **Ctrl+Alt**（`Scale`）。

-   **`0`、`1`、`2`、`3`**：快速对齐顶点、边、面或 3-胞体朝前。

-   **空格键**：画布获得焦点时暂停旋转和切片动画。

-   **`+` / `-`**（或 `=`）：加快或减慢切片动画速度。

## 移动端（触控）

-   **拖动、轻扫与点击**：旋转、平移、赋予旋转速度，或点击停止旋转。

-   **双指捏合与旋转**：双指捏合缩放多胞体；双指旋转可在屏幕平面内旋转。

-   **屏幕快捷键按钮（`S`、`C`、`A`）**：手机和平板默认显示（可在设置中
    开关），对应 Shift、Ctrl 和 Alt。

-   **屏幕平移/缩放按钮**：可在设置中启用。在 `Rotate R3` 下双击方向按钮
    可增加旋转速度，点击中间停止按钮可停止旋转。

## Android TV（方向键遥控器）

*本节仅适用于 Android TV 版本。*

-   **导航**：使用方向键和**确认**在顶部栏、屏幕旋转/缩放按钮和切片滑块
    之间移动。从顶部栏任意控件按**下**，或从切片滑块按**上**，都会将焦点
    移至中间旋转按钮。

-   **主动旋转模式**：

    -   在中间的**停止**按钮上**长按确认**即可进入**主动旋转模式**（中间
        按钮会变为高亮的地球图标）。

    -   **轻按方向键**：增加该方向的旋转速度。

    -   **长按方向键**：按住期间持续稳定旋转。

    -   **轻按确认**：停止旋转，同时保持在主动旋转模式中。

    -   **长按确认**或按**返回**：退出主动旋转模式。

-   **切片滑块**：聚焦滑块后按**确认**开始或停止向前动画，按**左 / 右**
    手动步进。

-   **设置**：按**上 / 下**逐行切换设置。在滑块设置上按**确认**进入编辑
    模式，用**左 / 右**调整数值，再按**确认**或**返回**退出编辑。
