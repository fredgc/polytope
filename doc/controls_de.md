# Steuerung

Die obere Leiste enthält mehrere Steuerelemente:

1. **Polytop-Typ**: Wählen Sie das anzuzeigende regelmäßige Polytop aus.

2. **Dimension**: Wählen Sie die Dimension (2 bis 5).

3. **Schnitt-Umschalter**: Schalten Sie den Hyperebenen-Schnitt ein oder aus.

4. **Transformationsmenü**: Wählen Sie Rotationsmodi (R3, R4, R5), Zolly oder
   Verschieben.

## Gesten & Geschwindigkeit

* **Ziehen**: Rotiert oder verschiebt das Polytop entsprechend dem aktiven
  Modus.

* **Scrollen / Zuziehen**: Zoomt oder skaliert das Polytop.

* **Schwungvolles Streichen**: Verleiht Schwung, sodass Rotation oder Schnitt
  sanft weiterlaufen.

* **Tippen**: Stoppt die Bewegung.

## Einrasten

Richten Sie das Polytop schnell so aus, dass eine Ecke, Kante, Fläche oder
3-Zelle direkt auf den Bildschirm zeigt.
