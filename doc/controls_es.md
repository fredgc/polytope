# Controles

La barra superior contiene varios controles:

1. **Tipo de politopo**: Seleccione el politopo regular a mostrar.

2. **Dimensión**: Elija la dimensión (de 2 a 5).

3. **Casilla de corte**: Active o desactive la intersección con el hiperplano.

4. **Menúde transformación**: Elija los modos de rotación (R3, R4, R5), Zolly
   o Trasladar.

## Gestos y velocidad

* **Arrastrar**: Rota o traslada el politopo según el modo activo.

* **Desplazar / Pellizcar**: Acerca o escala el politopo.

* **Deslizar rápido**: Otorga inercia para que la rotación o el corte
  continúen suavemente.

* **Tocar**: Detiene el movimiento.

## Alineaciones rápidas

Alinee rápidamente el politopo para que un vértice, borde, cara o 3-celda
apunte directamente hacia la pantalla.
