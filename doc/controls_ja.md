# 操作方法

上部バーには以下のコントロールがあります:

1.  **設定**（歯車アイコン）: 色、辺・頂点の太さ、線クリッピング、テーマ、
    画面上ボタンを設定します。

2.  **ポリトープの種類**: 表示する正ポリトープ（単体、立方体、正軸体、
    正十二面体、正二十面体、正24胞体、正120胞体、正600胞体）を選択します。

3.  **次元**: 次元（2〜5）を選択します。

4.  **スライス切替**: 超平面断面スライスの表示を切り替えます。

5.  **移動・変換メニュー**: ドラッグやボタンの動作（`Rotate R3`、`Rotate R4`、
    `Rotate R5`、`Zolly`、`Translate`、`Scale`）や向きスナップ（頂点、辺、面、
    3胞体を正面）を選択します。

6.  **ヘルプ**（`?`）と**言語**（地球アイコン）: ドキュメントの表示や言語の
    切り替えを行います。

## Web・デスクトップ（マウス＆キーボード）

-   **ドラッグ**: 現在の移動モードに応じて回転・遠近変更（`Zolly`）・平行
    移動・拡大縮小します。

-   **スクロールホイール**: ズームイン・ズームアウトします。

-   **フリック**: `Rotate R3` やスライススライダーに速度を与え、滑らかに動き
    続けさせます。

-   **クリック / タップ**: キャンバス上で回転を停止、またはスライス位置を移動
    して停止します。

-   **矢印キー**: 現在の移動ツールを適用します。

-   **`]` / `[`**（または **Page Up / Page Down**、テンキー **`+` / `-`**）:
    ズームイン・ズームアウトします。

-   **修飾キー**: **Shift**（`Rotate R4`）、**Shift+Ctrl**（`Rotate R5`）、
    **Ctrl**（`Zolly`）、**Alt**（`Translate`）、**Ctrl+Alt**（`Scale`）を
    押しながら操作します。

-   **`0`、`1`、`2`、`3`**: 頂点・辺・面・3胞体を正面にスナップします。

-   **Space**: キャンバスにフォーカスがあるとき、回転とスライスアニメーション
    を一時停止します。

-   **`+` / `-`**（または `=`）: スライスアニメーションの速度を増減します。

## モバイル（タッチ）

-   **ドラッグ・フリック・タップ**: 回転・移動・スピン付与、タップで回転停止。

-   **ピンチ＆ツイスト**: 2本指ピンチで拡大縮小、ひねりで画面内回転します。

-   **画面上ホットキーボタン（`S`、`C`、`A`）**: スマートフォンやタブレット
    では標準で表示され（設定で切替可能）、Shift / Ctrl / Alt の代わりになり
    ます。

-   **画面上パン／ズームボタン**: 設定で有効化できます。`Rotate R3` で矢印を
    ダブルタップすると回転速度が上がり、中央の停止ボタンで停止します。

## Android TV（D-Pad リモコン）

*このセクションは Android TV 版のみ対象です。*

-   **ナビゲーション**: D-Pad 矢印と**決定**で上部バー、回転／ズームボタン、
    スライススライダーを操作します。上部バーから**下**、またはスライス
    スライダーから**上**を押すと中央の回転ボタンにフォーカスします。

-   **アクティブ回転モード**:

    -   中央の**停止**ボタンで**決定を長押し**すると**アクティブ回転モード**に
        入ります（中央ボタンがハイライトされた地球アイコンに変わります）。

    -   **矢印を短押し**: その方向の回転速度を上げます。

    -   **矢印を長押し**: 押している間、一定のペースで回転し続けます。

    -   **決定を短押し**: アクティブ回転モードのまま回転を停止します。

    -   **決定を長押し**または**戻る**: アクティブ回転モードを終了します。

-   **スライススライダー**: フォーカスして**決定**を押すと前進アニメーションを
    開始／停止し、**左 / 右**で手動移動します。

-   **設定**: **上 / 下**で1行ずつ移動します。スライダー項目では**決定**で
    編集モードに入り、**左 / 右**で値を調整し、**決定**または**戻る**で確定
    します。
