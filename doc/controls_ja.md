# 操作方法

上部のバーには複数の操作項目があります：

1. **ポリトープの種類**:表示する正多胞体・正多面体を選択します。

2. **次元**:次元（2〜5）を選択します。

3. **断面の切り替え**:超平面による断面交差の表示を切り替えます。

4. **変換メニュー**:回転モード（R3、R4、R5）、ゾリー（Zolly）、移動を選択します。

## ジェスチャーと速度

* **ドラッグ**:現在のモードに応じてポリトープを回転または移動します。

* **スクロール/ピンチ**:ポリトープをズームまたは拡大縮小します。

* **フリック**:勢いを与え、回転やスライスが滑らかに継続します。

* **タップ**:動きを停止します。

## スナップ

頂点、辺、面、または3次元胞が画面の真正面を向くように素早く整列します。
