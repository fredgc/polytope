# Cortes

Para auxiliar na visualização de um polítopo n-dimensional, este programa
exibe a interseção do polítopo com um hiperplano (n-1)-dimensional. A
interseção tambéméum polítopo convexo, embora possa não ser regular. Quando o
corte estáativo, um controle deslizante na parte inferior da tela controla a
altura ou posição do hiperplano.

Para entender como funciona, comece com um cubo 3D. Clique no botão de corte.
Mover o controle deslizante mostra que a interseção de um cubo com um plano
paralelo a uma faceéum quadrado.

Girar o cubo com uma aresta para a frente produz um retângulo que se expande
atéum quadrado e se contrai novamente atéuma aresta. Girar com um vértice para
a frente produz um triângulo que se transforma em um hexágono regular no
centro do cubo.

Após familiarizar-se com os cortes 3D, tente cortar um hipercubo 4D com um
hiperplano tridimensional.
