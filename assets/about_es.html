Acerca de Polytope (v{{ VERSION }})

La Demostración de politopos es una aplicación educativa e interactiva diseñada para renderizar y visualizar politopos regulares y sus cortes transversales en 2, 3, 4 o 5 dimensiones.

Consulte el Resumen para obtener una explicación de los politopos, o consulte Controles para obtener instrucciones sobre el uso del programa.

Esta aplicación estáescrita en Dart con Flutter; el código fuente está disponible en GitHub en [https://github.com/fredgc/polytope][github].

¿Encontróun error o tiene una solicitud de función? [Abra un problema en GitHub][issues].

Puede encontrar otras aplicaciones y herramientas de dibujo en [www.gchouse.org][gchouse].

Privacidad y retención de datos

Este programa le permite personalizar configuraciones que se guardan localmente en su dispositivo (utilizando SharedPreferences / LocalStorage). No se recopilan datos personales.

En Android, las configuraciones locales se eliminan al desinstalar la aplicación. En la Web, las configuraciones se eliminan al borrar los datos de aplicaciones locales de su navegador.
